2. What unikeys is

unikeys shows the keyboard shortcuts of the editors and terminals you have installed in one table, lets you align them, and writes the result back into each app's own config file. It is a local tool: no account, no server, no sync. See the privacy page for exactly what data is involved.

3. What it costs

Nothing. unikeys is free to download and use, on as many of your own Macs as you like. There is no trial, no subscription, and no payment of any kind — which also means there is no paid support obligation, and no service level to promise you.

4. It writes to your files — your part of the bargain

This is the part that matters most. unikeys modifies real config files belonging to other applications. It is built to be careful about it: every pending change is listed before it saves, each file is copied into ~/Library/Application Support/unikeys/backups before the first write of a session, and a save can be reverted from those backups. But careful is not the same as infallible.

By using unikeys, you accept that:

  • You review the pending changes before you save. The list exists to be read, not clicked past.
  • You are responsible for your own backups. unikeys' backups are a convenience, not a backup system. Keep your configs in version control or Time Machine, as you would anyway.
  • Config formats change. The apps unikeys writes to are updated by other people on their own schedule. A format change can make a write wrong in a way unikeys cannot anticipate.
  • Some app fixtures are authored rather than captured from a real install, and are therefore likelier to be inaccurate. Which is which is documented in the project README; read it before your first save.

If a write goes wrong, tell us — open an issue at github.com/ronka/unikeys/issues. A reproducible report is the fastest way a bad fixture gets fixed for everyone.
